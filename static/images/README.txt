Put your product pictures in this folder.

Then open data/products.json and add an "image" line to a product:

  {"id": 4, "name": "Samsung Galaxy S24", ..., "icon": "phone", "image": "samsung-galaxy-s24.jpg"}

- Use the exact file name, including the extension (.jpg, .png, .webp, .svg).
- You can also use a full web address: "image": "https://example.com/phone.jpg"
- No image line, or a wrong file name? Dokan shows the icon instead.
- Best size: about 600 x 600 pixels, product on a plain or transparent background.
- Refresh the browser after changing a picture (Ctrl+Shift+R if you still see the old one).
